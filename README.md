# 프리파라HK 도우미

`pripara-arcade-supporter`는 Windows x64에서 티켓 이미지를 게임의 QR 입력으로 보내고, 코디와 사용자별 티켓을 한 창에서 관리하는 프로그램입니다. 현재 버전은 **2.3.0**입니다.

## 시작하기

1. Releases의 Windows 실행 패키지를 받아 압축을 풉니다.
2. `PriParaImageCamera.exe`, `_internal/`, `data.db`를 같은 폴더에 둡니다. 의상 사진과 3D 얼굴 미리보기를 사용하려면 `images.bin`도 함께 둡니다.
3. `PriParaImageCamera.exe`를 실행합니다. QR 연결 도우미에 관리자 권한을 허용합니다. 게임은 다른 폴더에 설치되어 있어도 실행 중인 `Prineo.exe`를 확인합니다.
4. QR 리더에서 티켓 이미지를 열거나 붙여 넣습니다. 게임의 읽기 요청이 초록색으로 표시되면 선택한 QR이 한 번 전달됩니다. 같은 QR을 다시 쓰려면 `QR 다시 보내기`를 누릅니다.

탭은 **QR 리더 → 코디 리모컨 → 마이티켓 → 우정티켓 → 캐릭터 생성 → 우정티켓 변환기** 순서입니다. 이름·메모·티켓·즐겨찾기는 이 PC의 실행 폴더 안에 저장합니다. 게임 실행 파일이나 카메라 드라이버는 이 프로그램에 포함하지 않습니다.

## 기능

- **QR 리더**: 기존 하부 카메라인 `PriPara QR Camera`를 기본 리더로 사용합니다. 이미지를 열거나 붙여 넣고, 최근 이미지와 보관함을 다시 사용할 수 있습니다.
- **큰 미리보기**: QR 리더의 이미지 영역을 화면 절반 크기로 시작하며 구분선을 끌어 가로 폭을 조절할 수 있습니다. 새 인쇄가 완료되면 그 마이티켓을 QR 리더에 자동 선택해 다음 게임에 사용할 수 있도록 준비합니다. 중복 인쇄 알림이나 목록 갱신은 다시 선택하지 않습니다.
- **직접 연결**: 사용자가 티켓을 선택하거나 `QR 다시 보내기`를 누르면 게임의 QR 읽기 요청에 맞춰 한 번 전달합니다. 화면 변경·정렬만으로 재전송하지 않습니다. 초록·주황·빨강 원으로 게임의 읽기 요청과 연결 상태를 표시합니다.
- **자동 재연결**: 게임이 켜져 있으면 앱 창을 닫아도 연결 도우미가 읽기 요청 상태를 유지합니다. 앱을 다시 열면 도우미를 이어받습니다. 이전 창의 QR 전송 대기와 코디 요청은 지우므로 재시작만으로 재전송하지 않습니다.
- **리모컨**: 의상세트·전체·부위별 검색, 브랜드 필터, ID·이름·등급 정렬, 즐겨찾기를 제공합니다. 게임의 코디 화면에서 선택한 의상을 적용합니다. `선택 즉시 게임에 입히기`는 첫 실행 때 켜져 있으며 사용자가 바꾼 설정을 유지합니다. 설정을 복원하는 것만으로 전송하지 않습니다.
- **티켓 보관함**: 티켓 코드 번호를 UID로 사용해 분류합니다. 왼쪽에 얼굴·닉네임·장수·사용자 메모를, 티켓 목록에 닉네임·UID·상의 명칭·인쇄 시각을 보여줍니다. 사용자 우클릭의 `메모하기`로 작성한 내용은 마이티켓과 우정티켓에서 공유합니다. 닉네임·ID·상의 ID 정렬과 이름·코디 명칭 검색도 지원합니다.
- **휴지통과 저장**: 티켓 목록과 이미지의 우클릭 메뉴에서 다른 이름으로 저장하거나 앱 휴지통으로 옮길 수 있습니다. `휴지통 보기`에서 이미지를 확인하고 복원하거나 영구 비우기를 선택합니다.
- **우정티켓 생성**: 우정티켓을 우클릭하면 해당 사용자를 고정하고 코디세트를 고릅니다. 리모컨의 코디세트를 우클릭하면 해당 세트를 고정하고 알고 있는 사용자를 고릅니다.
- **즐겨찾기**: 썸네일 왼쪽 위의 별만 표시합니다. 즐겨찾기에서도 우클릭해 우정티켓을 만들 수 있으며, 개별 의상이 여러 세트에 포함되면 먼저 세트를 고릅니다.
- **캐릭터 생성**: 기존 마이캐릭터 생성기의 이름·7종 파츠·좋아요 입력과 HK 마이티켓 QR 생성을 별도 탭에서 제공합니다. PNG 저장·복사·시작용 고정 QR을 사용할 수 있습니다. 생성한 프로필은 마이티켓 보관함에도 등록됩니다.
- **파츠 선택·미리보기**: 선택한 파츠는 하늘색 둥근 테두리로 표시하며 드래그는 하지 않습니다. 위아래 여백과 폼 휠 이동량 60%를 적용했습니다. 미리보기는 현재 폼의 외형을 사용하고 실패한 작업은 버튼으로 다시 요청할 수 있습니다.
- **등급**: 캐릭터 생성과 우정티켓→마이티켓 생성은 원본 좋아요별 등급표를 사용합니다. 예를 들어 20,000,000 좋아요는 등급 번호 30입니다. 검증되지 않은 운영 버전은 원본 기본 상한 33을 사용합니다. 이전 생성기의 좋아요는 있지만 등급이 0인 프로필로 우정티켓을 만들 때도 빠진 등급을 보정합니다.
- **메모·전체 검색**: 사용자 공통 메모 외에 개별 티켓에도 메모를 적을 수 있습니다. 티켓 메모는 날짜 아래에 표시하고 휴지통 복원에도 유지됩니다. 검색 기준은 전체·이름·코디 명칭·메모입니다.
- **사용자 선택**: 우정티켓 생성 화면에서 얼굴 위·이름 아래의 카드가 창 폭에 맞춰 배열됩니다. 마이티켓 사용자 메뉴에서도 우정티켓을 만들 수 있습니다.
- **우정티켓으로 마이캐릭터 생성**: 우정티켓 사용자 메뉴에서 같은 이름·외형·코디의 마이티켓을 만들고 좋아요를 지정합니다. 게임 시작 형식에서 보존되지 않는 ID 구성요소는 0으로 정규화하며, 이때 원본 ID와 생성될 ID의 차이를 생성 전에 표시합니다.
- **우정티켓 변환기**: 지원되는 KR K21·K31 우정티켓을 HK 앱 3번 형식으로 변환하고 보관함에 자동 등록합니다. 원래 등급·이름·외형·코디를 유지하며 확인되지 않은 원래 좋아요 수는 임의로 복구하지 않습니다. 복호화 자료는 별도로 공급해야 하며 아래 제한을 참고하세요.
- **인쇄물 저장**: 게임이 출력하는 BMP를 감시해 전체 티켓과 마이티켓·우정티켓 PNG를 저장합니다.

상부 카메라 탭과 상부 송출 기능은 없습니다. 이 앱 업데이트는 기존 드라이버 등록을 변경하지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `PriParaImageCamera.exe` | 통합 프로그램 |
| `_internal/` | 필수 Python·Qt·QR 해석·송출 라이브러리 |
| `data.db` | 교체 가능한 의상·세트·한글 명칭·아이템 부가값 |
| `images.bin` | 선택 사항인 의상 이미지·3D 얼굴 미리보기 자료 |
| `data/` | 실행 후 생성되는 티켓 색인과 즐겨찾기 |
| `channels/lower/data/` | 기존 QR 이미지 보관함 |

`images.bin`을 빼도 이름 목록·검색·리모컨·우정티켓 생성은 동작합니다. `data.db`가 없으면 QR 리더와 기존 티켓 조회를 사용할 수 있고, 의상 선택·새 우정티켓 생성은 사용할 수 없습니다. EXE와 `_internal/`는 함께 유지해야 합니다. 새 사용자 데이터 파일은 배포본에 포함하지 않습니다.

얼굴 썸네일은 기존 아틀리에의 모델 조합 렌더러로 얼굴·헤어·색·안경·원포인트를 조합한 256×256 이미지입니다. 목과 가슴 위쪽은 고정 레슨 의상을 사용합니다. 앱 시작과 티켓 등록 시 모든 등록 사용자의 얼굴을 자동 생성하며, 티켓 탭을 열거나 미리보기 버튼을 누를 필요가 없습니다. 같은 외형은 캐시를 공유합니다. 일시적인 실패는 간격을 두고 자동 재시도하며, 목록에 완료·대기·실패 상태를 표시합니다. `images.bin`과 시스템의 Edge 또는 Chrome이 필요하며, 설치된 브라우저의 개인 프로필을 사용하지 않습니다. 지원되지 않는 파츠는 다른 파츠로 대체하지 않습니다. 게임 화면과 픽셀 단위로 같은 결과를 보장하지 않습니다.

렌더링은 앱이 관리하는 **외부 Edge/Chrome의 숨김 프로세스**에서 수행하며, EXE 내부 렌더러만으로 처리하는 방식은 아닙니다. 별도 창을 열지 않습니다. 전용 프로세스와 임시 프로필·추출 자산은 작업 유휴 시점과 종료 시 정리하고 완성된 얼굴 PNG와 원래 `images.bin`은 유지합니다.

플레이어 코드는 12자리로 표시하지만 원본 게임이 유지하는 번호는 24비트 범위입니다. 임의의 12자리 수를 넣으면 로그인 뒤 원래 값이 유지되지 않습니다. 이 앱은 게임 실행 파일을 바꾸거나 범위 밖의 ID를 꾸며내지 않으며, 유효한 번호를 무작위로 만들고 앞자리는 0으로 표시합니다.

카메라 송출에는 기존 `PriPara QR Camera` 드라이버(`CAFE:0002`)가 필요합니다. QR 리더의 기본 영상은 640×480입니다. 직접 연결을 끄면 기존 QRReader와 가상카메라 경로를 사용할 수 있습니다.

지원하는 홍콩판 실행 파일과 데이터 구조를 기준으로 동작합니다. 다른 게임 버전에서 구조가 확인되지 않으면 전송하지 않고 연결 상태를 안내합니다.

## 우정티켓 이미지

생성한 PNG는 원래 우정티켓과 같은 **756×508**입니다. QR의 시작 위치 `(110,73)`와 180×180 크기를 맞추고, 게임 인식용 흑백 반전을 적용합니다. 사용자 닉네임·ID·외형·코디 명칭을 한글로 적으며, 원본 캐릭터 사진을 합성하지 않습니다.

원본 프로필을 유지하고 티켓 종류와 착용 코디 4부위를 바꿔 **HK 앱 3번 형식**으로 만듭니다. 이전 생성기의 좋아요는 있지만 등급이 0인 데이터는 빠진 등급도 보정합니다. 생성한 이미지를 저장한 뒤 QR을 다시 읽어 데이터가 일치하는지 검사합니다. 생성만으로 게임에 보내지 않으며, 미리보기의 `QR 리더에 불러오기`를 눌러야 합니다.

티켓 코드 번호와 UID는 같은 표시·분류 기준입니다. QR에 있는 별도의 내부 프로필 값은 원문 그대로 보존하며, 새로운 사용자 ID로 표시하지 않습니다. 기존 색인도 이 기준으로 갱신하며 티켓의 QR 원문을 다시 쓰지 않습니다. ID가 확인되지 않는 티켓은 임의 ID를 만들지 않습니다. 해석할 수 없는 QR도 삭제하지 않고 미확인 항목으로 보관합니다. 새 생성은 검증 가능한 HK 앱 2·3번 프로필에 한정합니다. KR·JP의 암호화 키는 배포 파일에 포함하지 않습니다.

## 한국판 변환 자료

KR 변환에는 사용자가 공급한 로컬 복호화 자료가 필요합니다. 기본 경로는 실행 폴더의 `data/private/kr_decoder.json`이며 변환 탭에서 다른 자료 파일을 선택할 수도 있습니다. 자료가 없으면 앱과 HK 기능은 정상 실행하고 KR 변환만 필요한 자료를 안내합니다. 실제 키 파일을 저장소·소스 ZIP·빌드 입력·릴리즈에 추가하지 마세요. 원래 사용자 티켓이나 개인 UID를 테스트 예제로 포함하지 않습니다.

지원하지 않는 한국판 파츠·코디는 기본 파츠로 몰래 바꾸지 않고 변환 불가 사유를 표시합니다. 공개 배포본은 복호화 자료 없이 제공되므로 자료를 따로 준비하기 전에는 KR 변환이 작동하지 않습니다.

## 자주 사용하는 작업

**코디 입히기**: 게임의 코디 선택 화면을 연 뒤 코디 리모컨에서 세트 또는 부위를 고릅니다. `선택 즉시 게임에 입히기`가 켜져 있으면 바로 요청하고, 꺼져 있으면 선택 후 `게임에 입히기`를 누릅니다. 별을 눌러 즐겨찾기에 넣을 수 있습니다.

**티켓 정리**: 마이티켓·우정티켓의 왼쪽에서 사용자를 고르고 이름·코디·메모로 검색합니다. 사용자 우클릭의 `메모하기`는 같은 사용자의 티켓들이 공유하는 메모이고, 개별 티켓 우클릭의 `메모하기`는 그 티켓에만 적용됩니다. 삭제한 이미지는 앱 휴지통에서 확인·복원할 수 있습니다.

**우정티켓 만들기**: 사용자 목록이나 의상 세트를 우클릭해 `우정티켓 생성하기`를 선택합니다. 얼굴 카드로 사용자를 확인하고 코디 세트를 고른 뒤 생성합니다. 생성된 PNG는 자동 보관하며, 게임에 표시하려면 미리보기의 `QR 리더에 불러오기`를 누릅니다.

**마이캐릭터 만들기**: 캐릭터 생성에서 이름·외형·좋아요를 정하고 QR을 만듭니다. `캐릭터 미리보기`로 현재 선택을 확인할 수 있습니다. 우정티켓에 있는 캐릭터를 바탕으로 만들 때는 우정티켓 사용자 메뉴의 `이 우정티켓으로 마캐 만들기`에서 좋아요를 입력합니다.

**한국판 우정티켓 가져오기**: 우정티켓 변환기에서 로컬 복호화 자료와 KR 이미지를 선택합니다. 변환에 성공한 HK 티켓은 우정티켓 보관함에 나타납니다. QR 검증 실패나 지원되지 않는 파츠가 있으면 사유를 표시하고 임의의 기본 캐릭터로 바꾸지 않습니다.

**인쇄물 자동 저장**: 표준 게임 설치 위치의 BMP 출력을 감시합니다. 화면 아래의 감시·저장 경로를 확인하세요. 다른 폴더를 사용할 때는 실행 폴더의 로컬 `ticket_settings.json`에서 `input_dir`을 게임의 BMP 출력 폴더, `output_dir`을 티켓 PNG 저장 폴더의 전체 경로로 지정합니다. 이 로컬 설정 파일은 공개 소스에 포함하지 않습니다.

## 구현

PySide6 화면과 로컬 SQLite 색인을 사용합니다. 증분 색인은 파일 크기·수정 시각이 달라진 이미지만 다시 해석합니다. QR 픽셀 읽기와 생성은 ZXing-C++를 사용합니다. 생성된 사용자 프로필은 실행 후 로컬 색인에만 보관합니다.

일반 권한 화면과 관리자 권한 연결 도우미를 분리합니다. 도우미는 기존 QRReader의 로컬 통신 방식으로 데이터를 전달하고, 리모컨은 실행 중인 `Prineo` 프로세스의 장면·자료 구조를 확인한 뒤 코디 요청을 보냅니다. 게임 폴더가 고정 경로일 필요는 없습니다. 리모컨 작업은 별도 작업자에서 순차 처리하여 QR 송출을 막지 않습니다.

도우미 연결은 프로세스 시작 시각·실행 파일·권한·로그인 세션과 통신 창 소유자를 확인합니다. 구형 도우미가 사라진 코디 화면은 검증된 실행 코드와 현재 친구 입력 단계가 모두 일치할 때만 읽기 요청을 복구합니다. 복구한 요청은 실제로 수신한 요청 횟수와 구분하고, QR 전송은 사용자의 새 선택을 기다립니다. 다른 버전이나 불명확한 상태에서는 복구를 추정하지 않습니다. 직접 연결을 명시적으로 끄면 기존 QRReader에 연결을 넘깁니다. 창과 게임이 모두 닫히면 도우미도 종료합니다.

외부 서버로 티켓·프로필·이미지를 업로드하지 않습니다. 네트워크 계정·암호·프로토콜 암호화 키나 개인 티켓은 기본값에 포함하지 않습니다.

`처음부터 마이캐릭터 생성하기`의 고정 시작 QR은 기존 웹앱에서 공개 제공한 이미지로, 비어 있는 데이터라고 가정하지 않습니다. 사용자가 만든 QR·이름·UID·메모와 렌더링 캐시는 로컬 실행 데이터이며 배포 자료에 포함하지 않습니다.
