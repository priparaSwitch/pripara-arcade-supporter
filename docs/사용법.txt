프리파라HK 도우미 v2.3.0

PriParaImageCamera.exe를 실행합니다. _internal 폴더와 data.db를 함께 둡니다.
images.bin은 선택 사항입니다. 없으면 의상 사진 대신 이름 목록을 사용합니다.

[QR 리더]
기존 하부 카메라를 기본 리더로 사용합니다. 상부 카메라는 없습니다.
이미지를 선택하거나 붙여 넣고 QR 다시 보내기로 한 번 전송합니다.
게임의 읽기 요청만으로 같은 티켓을 반복 전송하지 않습니다.
초록은 읽기 요청 중, 주황은 대기, 빨강은 연결 실패입니다.
게임을 켠 채 앱을 닫았다 다시 열어도 자동으로 연결을 이어받습니다.
다시 실행한 것만으로 이전 QR이나 코디를 재전송하지 않습니다.
직접 연결을 명시적으로 끄면 기존 QRReader 방식으로 돌아갑니다.
이미지 영역은 기본 절반 크기이며 가운데 구분선을 끌어 폭을 조절합니다.
새 마이티켓 인쇄가 완료되면 QR 리더에 자동 선택해 다음 게임을 준비합니다.

[코디 리모컨]
게임의 코디 화면에서 세트 또는 부위별 의상을 고르고 게임에 입히기를 누릅니다.
선택 즉시 게임에 입히기는 첫 실행 때 켜지며, 이후에는 바꾼 설정을 유지합니다.
목록은 창 크기에 맞춘 페이지로 표시되며 마우스 휠로 페이지를 넘깁니다.
썸네일 왼쪽 위의 별을 누르면 즐겨찾기를 추가하거나 해제합니다.
세트를 우클릭해 우정티켓 생성하기를 누르면 알고 있는 사용자를 고릅니다.
즐겨찾기에서도 우정티켓 생성하기를 사용할 수 있습니다.

[마이티켓 / 우정티켓]
티켓 코드 번호를 UID로 사용해 분류하며, 최신 티켓부터 표시합니다.
사용자 목록에 표준 얼굴·닉네임·장수·메모를 표시합니다.
얼굴은 앱 시작과 새 티켓 등록 시 자동 생성됩니다. 미리보기 버튼을 누를 필요가 없습니다.
생성 상태를 목록 위에서 확인할 수 있으며 일시적인 실패는 자동 재시도합니다.
사용자를 우클릭하고 메모하기를 누르면 메모를 작성할 수 있습니다.
개별 티켓도 우클릭해 메모를 적을 수 있으며 날짜 아래에 표시됩니다.
티켓 목록은 닉네임 * UID / 상의 코디명 / 인쇄 시각 순서입니다.
닉네임·ID·상의 ID 정렬, 이름·코디 명칭 검색도 사용할 수 있습니다.
검색의 전체는 이름·UID·코디·사용자 메모·티켓 메모를 함께 검색합니다.
메모 검색은 작성한 메모를 기준으로 검색합니다.
목록과 티켓 이미지를 우클릭해 다른 이름으로 저장하거나 휴지통으로 옮깁니다.
휴지통 보기에서 이미지를 확인하고 복원하거나 휴지통을 비울 수 있습니다.
우정티켓을 우클릭해 우정티켓 생성하기를 누르면 해당 사용자의 코디세트를 고릅니다.
마이티켓 사용자 메뉴에서도 우정티켓을 만들 수 있습니다.
우정티켓 사용자 메뉴의 이 우정티켓으로 마캐 만들기는 좋아요를 입력받아 마이티켓을 만듭니다.
원래 ID가 게임 시작 형식에서 유지되지 않는 경우 생성 전에 새 ID를 표시합니다.
새 우정티켓은 닉네임·생김새·코디 명칭과 QR을 표시하는 756×508 PNG로 저장됩니다.
생성만으로 게임에 전송하지 않습니다. 미리보기의 QR 리더에 불러오기를 눌러 사용합니다.

[캐릭터 생성]
이름·파츠·좋아요를 고르고 홍콩판 QR 만들기를 누릅니다.
선택된 파츠는 하늘색 둥근 테두리이며 폼 스크롤 이동량을 60%로 줄였습니다.
좋아요에 맞는 원본 등급을 지정합니다. 좋아요 2천만은 등급 번호 30입니다.
PNG 저장·이미지 복사·QR 리더로 불러오기를 사용할 수 있습니다.
처음부터 마이캐릭터 생성하기는 기존 웹앱의 공개 고정 시작 QR을 보여줍니다.
얼굴 미리보기에는 images.bin과 시스템 Edge 또는 Chrome이 필요합니다.
개인 브라우저 프로필은 사용하지 않으며 같은 외형의 얼굴은 캐시를 재사용합니다.
얼굴은 외부 Edge/Chrome의 숨김 프로세스로 렌더링합니다. 임시 작업 자료는 자동 정리합니다.
플레이어 코드는 원본 게임이 유지하는 유효 번호를 12자리로 표시하며 임의의 12자리 수는 지원하지 않습니다.

[우정티켓 변환기]
지원되는 한국판 우정티켓 이미지를 선택하면 홍콩판 앱 3번 형식으로 만들고 우정티켓 보관함에 등록합니다.
복호화 자료는 별도 로컬 파일이 필요합니다. 자료가 없으면 다른 기능은 사용 가능하며 변환에 필요한 자료를 안내합니다.
실제 복호화 자료를 공개 소스나 배포 ZIP에 넣지 마세요.

알 수 없는 QR은 삭제하지 않으며, 사용자 ID를 임의 생성하지 않습니다.
티켓·프로필·이미지는 외부 서버에 전송하지 않습니다.
자세한 기능과 구현은 README.md에 있습니다.
