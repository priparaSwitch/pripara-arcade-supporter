# 2.3.1 로컬 검증 범위

기록일: 2026-11-24. 이 버전은 End HK QR을 숨긴 게임 패치 V30의 연결 복구를 지원합니다. V29와 두 V30 배포 형태의 검토된 실행 파일 해시만 허용 목록에 추가했습니다. 실제 메모리에 적재된 원래 코드, QRReader DLL, DLL 연결 주소, 현재 장면과 컨트롤러 소유 관계, 완료·중지 상태, 프로세스 생성 시각 검사는 유지합니다. 화면과 티켓 형식은 바꾸지 않았습니다.

## 이번 버전에서 새로 수행한 검사

- 빈 개발자 프로필과 개인 환경 변수를 제외한 환경에서 실행 파일을 다시 빌드했습니다. 프로그램용 네이티브 송신 DLL과 데이터·이미지는 앞 버전과 같습니다.
- 실제 V29, V30 설치용, V30 공개용 실행 파일과 원본 QRReader DLL을 명시적으로 공급해 로컬 메모리 배열에 적재했습니다. 세 버전을 각각 네 가지 재배치 주소에서 검사하고, 게임 코드·DLL 코드·DLL 파일·연결 주소·미검토 실행 파일의 변조 거부 및 원상 복구 후 정상 판정까지 18개 검사를 통과했습니다. 실제 게임 프로세스는 열지 않았습니다.
- 기존 장면 상태·소유 관계·재배치·캐시 검사 8개와 읽기 요청 복구·중지·지연 결과·재전송 방지 검사 9개를 현재 소스로 다시 실행했습니다. 모두 통과했습니다.
- 소스 실행과 최종 실행 파일을 각각 빈 사용자 프로필에서 실행했습니다. 선택 자료인 `images.bin`이 없어도 실제 숨겨진 Qt 화면·SQLite·합성 PNG 처리 47개 검사가 통과했습니다. 실제 게임·카메라·장치·QR 통신을 여는 진입점은 차단했습니다.
- 최종 실행 파일에서 합성 자료로 KR K21/K31 변환·QR 재독해·보관·우정티켓에서 마이티켓 생성·취소·ID 정규화를 23개 항목으로 다시 확인했습니다. 키가 없는 기본 실행과 필요한 자료 안내도 검사했습니다. 이 검사에는 실제 복호화 키를 사용하지 않았습니다.

다음 두 명령은 실행 패키지에서 제공하는 자체 검사입니다. 첫 명령에는 `data.db`가 필요합니다. 결과 보고서는 지정한 위치에 생성됩니다.

```powershell
.\PriParaImageCamera.exe --offline-self-test report.json
.\PriParaImageCamera.exe --offline-conversion-self-test conversion-report.json
```

## 앞 버전에서 확인한 범위

2.3.0에서는 실제 숨김 브라우저를 사용한 자동 얼굴 생성·양쪽 보관함 썸네일 연결, 메모·시각·분류·휴지통·캐릭터 생성·즐겨찾기에서의 생성, 명시적으로 공급한 비공개 KR 자료의 변환을 확인했습니다. 해당 기능의 구현과 외부 자료는 이 버전에서 변경하지 않았습니다. 앞 버전의 검사를 이번 버전에서 새로 실행한 결과로 표시하지 않습니다.

얼굴 생성은 시스템 Edge 또는 Chrome을 별도 임시 프로필로 실행합니다. 현재 프로그램만으로 모든 얼굴 렌더링을 자체 처리하는 방식은 아닙니다. 실제 KR 복호화 자료와 개인 티켓·프로필·메모는 공개 패키지에 포함하지 않습니다.

## 한계

격리 실행, 현재 파일의 코드 판정 및 합성 통신 상태 검증 결과입니다. 새 게임 패치 V30과 도우미 2.3.1을 함께 사용한 실제 게임 로그인·인쇄·티켓 수신·프로그램 재시작 뒤 재연결은 사용자 플레이 확인이 별도로 필요합니다. 실제 게임 프로세스의 메모리나 화면을 조작하거나 입력을 전송하지 않았습니다.

공개 시작 QR, 게임·SDK·자산의 무결성 해시는 의도된 공개 검사 기준입니다. 개인 계정·티켓 식별자와 비공개 키를 대신 배포하는 값이 아닙니다. 최종 소스·압축 파일·실행 파일에 대한 개인정보 및 키 검사는 배포 준비 단계에서 별도로 수행합니다. 로컬 검증은 원격 커밋·릴리즈·과거 캐시·다른 사람의 복제본까지 검증했다는 뜻이 아닙니다.
